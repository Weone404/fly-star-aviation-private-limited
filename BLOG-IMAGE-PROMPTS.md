# Blog cover image prompts

For each new blog post, `coverImage` ships pointed at the site-wide fallback
(`/assets/hero-aircraft-1600w.jpg`) so nothing breaks. This file records the
intended real image so it can be generated by hand later. Once generated and
dropped at `public/blog/<slug>.webp`, update the post's `coverImage` field —
that step is manual, not automated.
