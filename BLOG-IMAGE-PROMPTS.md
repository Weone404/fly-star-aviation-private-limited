# Blog cover image prompts — Fly Star Aviation

One entry per post that still needs a cover. The scheduled run appends the entry
and points `coverImage` at the site-wide fallback; generating the image and
dropping it at `public/blog/<slug>.webp` is a manual step afterwards. Once the
file exists, update that post's `coverImage` and strike the entry here.

Every prompt ends with the house style line so covers stay consistent:

> Flat vector illustration, minimal clean style, professional Indian aviation
> training context, generous negative space, absolutely NO text, words, letters,
> numbers or signage anywhere in the image.
